Fashion Trends Analysis
About the Project
This project analyzes fashion retail data using Python to understand brands, product categories, prices, and discounts.
Objectives
- Identify popular brands and product categories.
- Analyze product prices and discounts.
- Compare preferences across gender groups.
- Study Budget, Mid, Premium, and Luxury price segments.
- Understand discount patterns.
Tools Used
Python, Pandas, NumPy, Matplotlib, and Seaborn.
Methodology
1. Clean the dataset and handle missing values.
2. Perform Exploratory Data Analysis (EDA).
3. Analyze brands, categories, and product types.
4. Compare discounts and prices using charts.
5. Study gender preferences and price segments.
Conclusion
This project helps identify fashion product trends, pricing patterns, and discount strategies through Python data analysis.
